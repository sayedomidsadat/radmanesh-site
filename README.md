# راهنمای وب‌سایت SAYED OMID RADMANESH

## ویرایش (بدون برنامه‌نویسی)
همه متن‌ها، لینک‌ها، شماره‌ها و ویدیوها فقط در فایل **config.js** هستند. با Notepad باز کنید، فقط متن داخل "" را عوض کنید و ذخیره کنید.
- **عکس پروفایل:** عکس جدید را در `assets/images` بگذارید و مقدار `photo` را عوض کنید.
- **ویدیو:** `url` را عوض کنید. یوتیوب و آپارات داخل سایت پخش می‌شوند؛ تیک‌تاک در خود تیک‌تاک باز می‌شود.
- **عنوان و توضیح ویدیوهای ۲ تا ۴** را خودتان در `title` و `desc` بنویسید (عنوان آن‌ها را نمی‌دانستم).
- **ویدیوی ۵ و ۶:** فعلاً فقط «طرح و سناریو» هستند و ویدیوی تولیدشده نیستند. بعد از ساخت ویدیو، لینکش را در `url` بنویسید تا کارت به ویدیوی واقعی تبدیل شود.

## انتشار رایگان با GitHub Pages
1. در github.com حساب بسازید و Repository جدید (Public) با نام دلخواه بسازید.
2. **Add file ← Upload files**: همه فایل‌ها و پوشه‌های داخل ZIP (نه خود ZIP) را آپلود و Commit کنید.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save**.
4. بعد از چند دقیقه، آدرس `https://USERNAME.github.io/REPO` فعال می‌شود.
5. برای پیش‌نمایش لینک در شبکه‌های اجتماعی، در `index.html` مقدار `og:image` را به آدرس کامل تصویر تغییر دهید، مثلاً `https://USERNAME.github.io/REPO/assets/images/og.jpg`.
